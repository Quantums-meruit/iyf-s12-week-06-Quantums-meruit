Revision notes

  • Callback: a function passed to another function to run later.
  • Promise: an object representing a future result; it can be pending, fulfilled or rejected.
  • .then(): handles a fulfilled Promise and can return a value or another Promise.
  • Promise.all(): waits for every Promise; it rejects if any input Promise rejects.
  • Promise.race(): settles with the first input Promise to settle.
  • async/await: syntax that makes Promise-based code read in a sequential style.
  • try/catch/finally: handles errors and runs cleanup code whether the operation succeeds or fails.

NB: await pauses the current async function, not the whole browser. Use Promise.all() when independent requests can run in parallel.
