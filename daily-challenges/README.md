# Daily Challenges

The five required asynchronous JavaScript challenges are runnable from the [Daily Challenges page](../daily-challenges.html).

1. **Day 1 — Delayed Promise:** resolve a Promise after a two-second delay.
2. **Day 2 — Promise chain:** run three asynchronous tasks in sequence and measure elapsed time.
3. **Day 3 — Error handling:** handle a 404 response with a fallback user object.
4. **Day 4 — Callback to async/await:** wrap a callback-style operation in a Promise and await it.
5. **Day 5 — Parallel fetches:** run three requests concurrently and inspect every outcome with `Promise.allSettled()`.

The interactive page and its event handlers remain in the repository root as `daily-challenges.html` and `daily-challenges.js`, so existing navigation and deployment paths remain simple.
